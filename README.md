# Recursos CYR

Recursos de Computación y Robótica para 3.º ESO.

## Actividades

- [Arrastra las etiquetas HTML](html/arrastra-las-etiquetas.html): ejercicio autocorregible con 20 huecos, etiquetas de apertura y cierre y reintentos. Se puede usar arrastrando o haciendo clic. Funciona también sin conexión al descargar el archivo HTML.

## Sitio publicado

- [Portada](https://josetomastocino.github.io/Recursos-CYR/)
- [Abrir el ejercicio](https://josetomastocino.github.io/Recursos-CYR/html/arrastra-las-etiquetas.html)

GitHub Pages publica la raíz de la rama `main`. Para incorporar más recursos, añade sus archivos y enlázalos desde `index.html`.

Las actividades actuales funcionan en el navegador y no envían resultados a Classroom ni almacenan calificaciones en un servidor.
